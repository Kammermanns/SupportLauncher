# Privacy policy

SupportLauncher does not collect, store or transmit personal data.

**Network access.** When started, the program makes exactly one kind of request: an HTTPS download of the file at `DownloadUrl` in `launcher.ini`. Like any web request, this reveals the PC's IP address and the user agent `SupportLauncher/1.0` to the operator of that server (and, for the default configuration, to TeamViewer). No other data is sent. There is no telemetry, no update check and no analytics.

**Local data.** The downloaded file is stored in `%LOCALAPPDATA%\SupportLauncher` so it can be used when the PC is offline. Uninstalling removes this folder.

**Third parties.** The program that is downloaded and started (for example TeamViewer QuickSupport) has its own privacy policy, which applies once it runs.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
